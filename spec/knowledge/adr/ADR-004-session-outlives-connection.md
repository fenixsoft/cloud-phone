# ADR-004：会话生命周期优先于连接生命周期

date: 2026-11-08
status: accepted

## Context

云端手机范式要求「断开挂机、回来自动继续」：用户退出观看后源端应用的状态与画面不能随连接断开而丢失，重连须即时恢复。

## Decision

源端前台服务内 SessionManager 持有虚拟屏与 App 进程；连接断开只停止编码与传输，不销毁虚拟屏、不杀其上 App；同 token 重连立即请求 IDR 秒回画面；支持至少 2 个单应用会话同时挂机。

## Consequences

挂机会话持续占用源端内存与虚拟屏资源；客户端的会话抽屉、桌面快捷方式与应用列表等能力均以「会话在线可恢复」为前提。
