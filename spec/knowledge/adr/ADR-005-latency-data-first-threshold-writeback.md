# ADR-005：延迟修复数据先行，验收阈值放宽必须回写 SPEC

date: 2026-11-09
status: accepted

## Context

真机首测出现「触摸几秒才有一次反应」，初步归因静屏合成慢但未经测量；模拟器 swiftshader 软渲染与真机硬件合成的延迟口径差异大，阈值若只记运行笔记会使 SPEC 验收门与实门口径脱节。

## Decision

性能/延迟类修复必须先全链插桩测量、按数据定位主延迟段再改代码，禁止未测量就定论、禁止盲改；验收阈值如因平台瓶颈需放宽，必须同步修订对应 SPEC Scenario 阈值并在设计文档留下数据依据，不得仅记 device-notes 而使验收门与实门口径脱节、静默放水；所有 Scenario 验收数据必须来自真实运行（禁止伪造验收）。

## Consequences

每次延迟修复可回溯到分段测量数据，阈值调整留痕可审计；代价是修复前需投入插桩与测量脚本建设。
