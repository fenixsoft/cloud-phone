# 客户端界面壳

<!-- knowledge: capability=client-ui-redesign rev=1
     sources=spec/changes/client-ui-redesign -->

客户端 App 的整体界面壳：连接首页（局域网发现 + 档案卡片 + 手动建档）、全幅画面控制台（HUD 统计条 + 工具坞 + 虚拟导航键 + 会话抽屉）、单应用磁贴列表与设置页，构成「云手机遥控器」的全部四屏呈现层。

## 规则

- 入口结构：连接首页为应用唯一 LAUNCHER 入口，单 Activity 多区块滚动结构（ScrollView 内动态挂载卡片 item，View 体系零新依赖）。
- 局域网源端发现：进入首页自动扫描所在局域网子网，对候选地址的 TCP 22333 端口发起探测——仅 TCP connect 判定服务存在，不完成 A2A 配对握手；网段取本机 IP 与前缀，无 WiFi 信息时回退 192.168 / 10. 常见网段（每段遍历 254 地址）。
- 探测纪律：后台线程执行不阻塞 UI；总时长上限 10s（超时即收尾）、单地址超时 300ms、并发 64；重复地址去重；单个地址超时不拖慢整体完成。进入首页仅自动扫描一次，其余经「重试扫描」手动触发。
- 发现呈现三态完整：扫描中（含进度计数）→ 有发现 / 未发现；未发现时显示空态引导（可能原因说明 + 「手动新建连接」 + 「重试扫描」），常驻「新建连接」入口在任何状态下均可用。
- 探测不握手：发现卡的传输后端标识按 host+port 匹配既有档案显示其后端，未匹配的新发现源端显示默认 lan-direct——探测结果不得用作真实传输后端的判定。
- 发现结果不自动写入档案库（避免误报污染），仅本次列表呈现；与既有档案按 host+port 匹配的标注「已保存」。
- 曾保存档案但本次探测 22333 无响应的源端卡片以「无响应」态呈现（视觉弱化、连接按钮置不可达禁用），不参与可连接列表。
- 首页信息架构自上而下：顶栏（标题、设置入口、会话抽屉入口）、网络状态徽章、扫描面板、发现的源端卡片列表、手动保存的档案卡片列表、常驻「新建连接」入口。
- 卡片动作：在线源端卡片提供「连接」（进入控制台）与「单应用」（建立连接后直达该源端应用列表）；档案卡片提供「连接」与「删除」（无响应档案的连接禁用，删除始终可用）。一键连接以卡片地址/端口/后端/token 发起（档案无 token 按既有连接规则处理）；连接失败与握手被拒原因以状态文本 + toast 回显。
- 手动新建连接为底部弹层表单，字段布局固定：连接名称（可选）、主机地址/IP（独占一行）、TCP/UDP 端口（同行并排，默认 22333/22334）、传输后端三选一 lan-direct/p2p/frp（默认 lan-direct）、配对 token（密码态输入）、高级选项折叠区（分辨率默认「跟随本机」/帧率 60/码率 8 Mbps/观看模式整屏镜像）。
- 表单保存校验主机地址非空（为空提示且不保存）；成功后 toast 确认、档案卡片实时追加并可立即连接，重启客户端后仍存在。档案复用 source-profiles 既有持久化存储；删除档案即卡片移除 + 持久化同步删除 + 计数更新。
- 控制台：连接成功进入全幅画面控制台，画面区呈现源端系统镜像（复用既有解码渲染管线）；顶部 HUD 统计条显示 FPS/码率/RTT/丢包（复用既有 STATS 统计上报）与分辨率读数（取解码输出 MediaFormat 实际值——STATS 消息无分辨率字段），间隔刷新。
- 底部工具坞吸底且可一键收起留把手（避免遮挡触控区，触控坐标换算沿用既有渲染 surface 逻辑）：键盘唤起、截屏（保存客户端本地、toast 确认、会话不中断）、串流档位循环切换、旋转（仅切换客户端本地横竖屏呈现，不改源端）、单应用入口、断开。
- Android 虚拟导航键：BACK 经既有 INPUT_EVENT InputAction.BACK 注入源端；HOME/RECENTS 协议无对应消息，仅预留占位，不得为其扩展协议或改动源端。
- 会话抽屉为控制台内自画面边缘唤出的滑出面板，含挂起（画面停更、状态标注挂起）/恢复（秒回出帧）与断开（回连接首页），衔接既有会话生命周期语义。
- 档位切换按 1080P·60 → 720P·60 → 1080P·30 → 自定义 顺序循环：以新档位参数重发整屏 START_SESSION（控制链路保持不断开），源端按新参数重建采集/编码管线后经 IDR 秒回恢复画面——既有语义为「同一会话内不改参数」，不得表述或实现为同会话内原地改参。
- 单应用列表：自控制台「单应用」入口（或首页在线源端卡「单应用」直达，均先建会话）进入应用列表页，应用以磁贴网格呈现，每磁贴仅含应用图标（通用占位）与应用名称（深色底白色文字），不显示包名；搜索框按名称实时过滤；磁贴右上角图钉创建桌面快捷方式（复用 app-shortcuts 能力，直达 cloudphone://launch 单应用）。
- 单应用画面：点选磁贴打开虚拟屏单应用会话，顶部显示「单应用 · <应用名>」模式徽章，徽章一键退出返回系统画面控制台，会话保持。
- 设置页：首页顶栏入口进入独立设置页，分组为外观（主题/深色模式开关，MVP 允许占位）、串流档位默认值（分辨率/帧率/码率）、传输偏好（默认端口 22333 展示与修改）、触控输入（占位）、安全（预留）、关于（版本号、检查更新）；未实现项显式标注「预留」且点击无效，不得伪装为可用功能。
- 设置项变更持久化并在下次会话生效（会话中项于下次连接生效）：串流默认档位反馈为新建连接表单高级选项默认值，默认端口供局域网扫描读取。
- 视觉语言：全屏深色 HUD 风——深空黑底 #0B0B10、发射蓝强调 #3B82F6、语义色 ok #34D399 / warn #F59E0B / danger #EF4444，mono 字体仅用于数据读出；色板与样式族落 res/values（colors.xml / themes.xml，主题 Theme.CloudPhone.Hud）。信息架构与状态流转以 SPEC Scenario 为准，原型视觉参照不构成约束。

## 代码锚点

- 主实现：client/app/src/main/kotlin/cloudphone/client/ConnectActivity.kt（连接首页与卡片动作）、client/app/src/main/kotlin/cloudphone/client/DecodeRenderActivity.kt（控制台 HUD/工具坞/导航键/会话抽屉面板）
- 单源符号：client/app/src/main/kotlin/cloudphone/client/discovery/LanScanner.kt（子网 22333 探测）、client/app/src/main/kotlin/cloudphone/client/ui/ManualConnectSheet.kt（新建连接底部表单）、client/app/src/main/kotlin/cloudphone/client/SettingsActivity.kt（设置页）
- 消费方：client/app/src/main/kotlin/cloudphone/client/SourceAppsActivity.kt（单应用磁贴列表页）、client/app/src/main/AndroidManifest.xml（入口与 Activity 注册）
- 守卫测试：无
