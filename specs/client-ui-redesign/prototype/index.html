原型说明

层级：plain 仿样（无约束力）。工程无 Web 组件库，页面内所有设备 / 应用 / 数据均为示例假数据。

设计候选来源：ui-ux-pro-max --design-system（HUD / 星白 #F8FAFC + 发射蓝 #3B82F6 + 深空黑 #0B0B10），经反俗套自批判修订（发光仅限状态点与扫描线、无渐变横幅、mono 仅用于数据读出）；工程无 DESIGN.md，候选不覆盖任何既定设计语言。

页面中蓝色=主行动，绿色=在线/健康，琥珀=挂起/单应用，红色=断开/危险。
